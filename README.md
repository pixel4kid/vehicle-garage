## Development

Requirements: **Node.js 22+**. For building the APK locally you also need **JDK 21** and the **Android SDK** (easiest: install [Android Studio](https://developer.android.com/studio)).

```bash
npm install
npm run dev            # run in the browser at http://localhost:5173
```

Build and run on Android:

```bash
npm run android:sync   # build the web app and copy it into the Android project
npm run android:open   # open in Android Studio, then press Run
```

Or build an APK from the command line:

```bash
npm run android:sync
cd android
./gradlew assembleDebug   # output: android/app/build/outputs/apk/debug/app-debug.apk
```

### Project structure

```
src/
  App.tsx            screen stack navigation + Android back button
  store.ts           all data and actions, saved to localStorage
  utils.ts           formatting, stats, fuel economy, reminder logic
  backup.ts          JSON / CSV export and import
  screens/           Home, Vehicle (logs / reminders / stats), forms, settings
  components/        shared UI pieces and icons
android/             native Android project (generated by Capacitor)
assets/              app icon and splash source images
```

## Releasing a new version

1. Bump `version` in `package.json` (and `versionCode` / `versionName` in `android/app/build.gradle`).
2. Commit, then tag and push:
   ```bash
   git tag v1.1.0
   git push origin main --tags
   ```
3. GitHub Actions builds the APK and attaches it to a new release automatically.
